# CareLoop web

React and TypeScript starter for the demo UI. From this directory, run `npm ci`, `npm run dev`, `npm run lint`, and `npm run build`.

The initial screen is a scaffold only. Connect it to the API through an agreed read contract; do not make the browser or simulator a second source of case data.

Screen designs are in [docs/ui-design](../../docs/ui-design/README.md). This app builds the worklist, case and impact screens (1, 2 and 6).
